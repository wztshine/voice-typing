# ============================================================
#  语音打字 (voice-typing) 自定义热词模板
#  本文件是原始模板备份; 实际生效的是同目录的 hotwords.txt (随仓库分发, 改它即可)
# ------------------------------------------------------------
#  一行一个词。程序会：
#    1. 解码时给这些词加偏置（让模型更愿意输出它们）
#    2. 输出后把英文大小写修成你写的标准写法
#
#  写法说明：
#    - 中文直接写，例如：知识库
#    - 英文直接写，例如：Typora   （输出会保持这个大小写）
#    - 带数字的词无法生效（模型的词典里没有数字）
#    - 以 # 开头的行是注释
#
#  改完保存，双击「重启语音输入.bat」生效。
#  偏置强度在 config.json 里的 hotword_bonus（默认 2.0，4~6 更强势）
# ============================================================

# --- 示例（把行首的 # 去掉即启用）---
